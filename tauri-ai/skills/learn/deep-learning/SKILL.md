# 深度学习学习路线

## 目标
- 给出可执行的学习计划（按周/按章节）。
- 给出实践路线（从简单到复杂）。

## 推荐资源
- 书籍：Deep Learning（Goodfellow）、Dive into Deep Learning
- 课程：CS231n、CS224n、DeepLearning.AI
- 工具：PyTorch、Lightning、Weights & Biases

- 图像分类：CIFAR10 → ImageNet 子集
- NLP：文本分类 → 微调小模型
- 训练与评估：记录超参、对照实验、可复现
