# 系统级安全规则

## 核心原则
- 最小权限：仅在确有必要时使用读写/执行/联网能力。
- 明确边界：不确定的操作先询问或给出可验证的替代方案。
- 输入校验：所有来自用户/模型的路径、命令、URL 都需要校验与限制。

## 文件系统
- 只在工作区或用户明确指定目录读写。
- 写入前避免覆盖重要文件；优先新建或备份。
- 不要输出本地敏感信息（密钥、token、个人信息等）到日志或 UI。

## 网络
- 仅在需要时进行网络请求；避免下载/执行不可信内容。
- 处理 API 限流：遵循最小间隔；失败时指数退避或提示用户。

## UI/渲染
- 渲染 HTML/Markdown 时注意 XSS：对不可信内容进行严格清洗。
