# 需求文档：紧凑附件预览

## 简介

本功能旨在恢复一个在合并时丢失的特性：附件预览应该默认以紧凑的图标形式显示，用户可以点击展开查看详细内容。当前系统中已经存在一个实现了紧凑显示和展开功能的 `AttachmentPreview` 组件，但 `InputArea` 组件仍在使用总是显示完整内容的 `TextFilePreview` 和 `PdfPreview` 组件，导致附件占用过多空间。

本需求将统一使用 `AttachmentPreview` 组件来显示所有类型的附件（图片、文本文件、PDF），提供一致的用户体验和更好的空间利用率。

## 术语表

- **AttachmentPreview**: 统一的附件预览组件，支持紧凑显示和展开功能
- **InputArea**: 聊天输入区域组件，包含文本输入框和附件预览区域
- **TextFilePreview**: 当前使用的文本文件预览组件（总是显示完整内容）
- **PdfPreview**: 当前使用的 PDF 预览组件（总是显示完整内容）
- **紧凑模式**: 附件以小图标形式显示，仅显示文件类型图标、文件名和大小
- **展开模式**: 附件显示详细内容，包括图片预览、文本内容或 PDF 页面缩略图

## 需求

### 需求 1：统一附件预览组件

**用户故事：** 作为用户，我希望所有类型的附件都使用统一的预览方式，这样界面更加一致且节省空间。

#### 验收标准

1. WHEN 用户添加图片附件 THEN 系统应使用 AttachmentPreview 组件显示该附件
2. WHEN 用户添加文本文件附件 THEN 系统应使用 AttachmentPreview 组件显示该附件
3. WHEN 用户添加 PDF 附件 THEN 系统应使用 AttachmentPreview 组件显示该附件
4. THE InputArea 组件应移除对 TextFilePreview 和 PdfPreview 组件的直接使用

### 需求 2：紧凑模式显示

**用户故事：** 作为用户，我希望附件默认以紧凑的图标形式显示，这样可以在输入区域看到更多内容。

#### 验收标准

1. WHEN 附件首次添加到输入区域 THEN 系统应以紧凑模式显示该附件
2. WHILE 附件处于紧凑模式 THEN 系统应显示文件类型图标、文件名和文件大小
3. WHILE 附件处于紧凑模式 THEN 系统应显示向右箭头图标指示可以展开
4. THE 紧凑模式下的附件应占用最小的垂直空间

### 需求 3：展开功能

**用户故事：** 作为用户，我希望能够点击附件查看详细内容，以便在发送前确认附件内容正确。

#### 验收标准

1. WHEN 用户点击紧凑模式的附件 THEN 系统应展开该附件显示详细内容
2. WHILE 附件处于展开模式 THEN 系统应显示向下箭头图标指示可以收起
3. WHEN 用户点击展开模式的附件头部 THEN 系统应收起该附件回到紧凑模式
4. WHILE 图片附件展开 THEN 系统应显示图片预览
5. WHILE 文本文件附件展开 THEN 系统应显示文本内容预览（最多 500 字符）
6. WHILE PDF 附件展开 THEN 系统应显示 PDF 元数据、页数和页面缩略图（最多 6 页）

### 需求 4：移除按钮

**用户故事：** 作为用户，我希望能够轻松移除不需要的附件，无论附件是紧凑模式还是展开模式。

#### 验收标准

1. WHEN 用户悬停在附件上 THEN 系统应显示移除按钮
2. WHEN 用户点击移除按钮 THEN 系统应从输入区域移除该附件
3. THE 移除按钮应在紧凑模式和展开模式下都可用
4. THE 移除按钮应位于附件的右上角

### 需求 5：PDF 调试模式支持

**用户故事：** 作为开发者，我希望在调试模式下能够选择 PDF 的页面范围和内容选项，以便测试不同的 PDF 处理场景。

#### 验收标准

1. WHERE PDF 调试模式启用 WHEN PDF 附件展开 THEN 系统应显示页面范围选择控件
2. WHERE PDF 调试模式启用 WHEN PDF 附件展开 THEN 系统应显示"包含图片"和"包含文本"复选框
3. WHEN 用户修改页面范围 THEN 系统应更新 PDF 附件的页面范围设置
4. WHEN 用户切换"包含图片"选项 THEN 系统应更新 PDF 附件的图片包含设置
5. WHEN 用户切换"包含文本"选项 THEN 系统应更新 PDF 附件的文本包含设置

### 需求 6：布局和样式一致性

**用户故事：** 作为用户，我希望新的附件预览方式与现有界面风格保持一致，提供流畅的用户体验。

#### 验收标准

1. THE 附件预览应使用与现有组件一致的颜色方案和圆角样式
2. THE 附件预览应支持深色模式
3. THE 附件预览应在悬停时提供视觉反馈
4. THE 附件预览应使用平滑的过渡动画
5. THE 多个附件应以网格或列表形式整齐排列
