# 实现计划：紧凑附件预览

## 概述

本实现计划将 `InputArea` 组件从使用独立的 `TextFilePreview` 和 `PdfPreview` 组件迁移到统一使用 `AttachmentPreview` 组件。主要工作包括：
1. 修改 `InputArea` 组件的导入和渲染逻辑
2. 添加 PDF 调试模式支持
3. 更新相关测试

## 任务

- [x] 1. 修改 InputArea 组件以使用统一的 AttachmentPreview
  - [x] 1.1 更新导入语句
    - 移除 `TextFilePreview` 和 `PdfPreview` 的导入
    - 添加 `AttachmentPreview` 的导入
    - _需求：1.4_

  - [x] 1.2 添加 PDF 调试模式支持
