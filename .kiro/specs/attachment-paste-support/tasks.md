# 实现计划：附件复制粘贴功能

## 概述

本实现计划将扩展 InputArea 组件的 handlePaste 函数，添加 PDF 文件粘贴支持，并改进多文件粘贴处理、错误处理和用户反馈机制。实现将基于现有的附件系统架构，保持代码一致性和向后兼容性。

## 任务

- [x] 1. 扩展 handlePaste 函数支持 PDF 文件
  - 在 handlePaste 函数中添加 pdfFiles 数组用于收集 PDF 文件
  - 添加 PDF 文件类型检测逻辑（application/pdf 或 .pdf 扩展名）
  - 当检测到 PDF 文件时，将其添加到 pdfFiles 数组
  - 在处理完所有文件后，调用 handlePdfSelect 处理 PDF 文件
  - 更新依赖数组，添加 handlePdfSelect
  - _需求：1.1, 1.2_
