📝 用例规划

版本: v0.1 MVP | 状态: 评审中 | 更新: 2026-01-03

概览

本文档定义 TauriAI MVP 版本的核心用例，共 16 个用例，分为 4 个模块。

模块 用例数 优先级
应用生命周期 4 P0
对话交互 6 P0
模型配置 5 P0
快捷操作 1 P1

1. 应用生命周期

UC-01 启动应用

优先级: P0 | 参与者: 用户

描述：用户启动应用，应用最小化到系统托盘

主流程
  1. 用户双击应用图标或从开始菜单启动
  2. 应用初始化，加载配置
  3. 托盘图标出现在系统托盘区
  4. 主窗口默认隐藏（或根据设置显示）

UC-02 打开主窗口

优先级: P0 | 参与者: 用户

描述：用户点击托盘图标，打开主窗口

主流程
  1. 用户单击托盘图标
  2. 主窗口显示并获得焦点
  3. 输入框自动聚焦，准备输入

⚠️ macOS 注意：由于系统限制，macOS 上需通过托盘菜单「显示窗口」操作，左键单击可能不触发。

UC-03 关闭窗口保持运行

优先级: P0 | 参与者: 用户

描述：用户关闭窗口，应用继续在托盘运行

主流程
  1. 用户点击窗口关闭按钮
  2. 主窗口隐藏
  3. 应用继续在托盘运行
  4. 托盘图标保持可见

UC-04 完全退出应用

优先级: P0 | 参与者: 用户

描述：用户从托盘菜单退出，完全关闭应用

主流程
  1. 用户右键点击托盘图标
  2. 选择「退出」菜单项
  3. 保存当前状态和配置
  4. 应用完全退出，托盘图标消失

2. 对话交互

UC-05 发送消息获取回复

优先级: P0 | 参与者: 用户, AI 服务

描述：用户发送消息，获取 AI 回复

主流程
  1. 用户在输入框输入消息
  2. 按 Enter 或点击发送按钮
  3. 消息显示在对话区域
  4. 显示加载状态
  5. 调用 AI API 获取回复
  6. AI 回复显示在对话区域
异常流程
  1. API 调用失败 → 显示错误提示，允许重试
  2. 网络超时 → 显示超时提示

UC-06 流式输出显示

优先级: P0 | 参与者: 用户, AI 服务

描述：AI 回复以流式方式实时显示

主流程
  1. 发送请求后，建立 SSE/Stream 连接
  2. 收到第一个 token，开始显示回复
  3. 持续接收 token，实时追加显示
  4. 流结束，回复完成

UC-07 多轮对话

优先级: P0 | 参与者: 用户

描述：用户进行多轮对话，AI 保持上下文

主流程
  1. 用户发送第一条消息，获取回复
  2. 用户继续发送后续消息
  3. 系统将历史消息作为上下文发送给 AI
  4. AI 基于上下文生成连贯回复

UC-08 新建对话

优先级: P0 | 参与者: 用户

描述：用户新建对话，清空当前上下文

主流程
  1. 用户点击「新建对话」按钮
  2. 当前对话自动保存到历史
  3. 对话区域清空
  4. 上下文重置，准备新对话

UC-09 查看历史对话

优先级: P0 | 参与者: 用户

描述：用户查看和恢复历史对话

主流程
  1. 用户点击「历史」按钮或侧边栏
  2. 显示历史对话列表（按时间排序）
  3. 用户选择某条历史对话
  4. 加载该对话内容和上下文

UC-10 复制消息内容

优先级: P0 | 参与者: 用户

描述：用户复制对话中的消息内容

主流程
  1. 用户将鼠标悬停在消息上
  2. 显示复制按钮
  3. 用户点击复制按钮
  4. 内容复制到剪贴板，显示成功提示

3. 模型配置

UC-11 添加模型配置

优先级: P0 | 参与者: 用户

描述：用户添加新的 AI 模型配置

主流程
  1. 用户打开设置页面
  2. 点击「添加模型」按钮
  3. 选择 Provider（OpenAI / Anthropic / Ollama / 自定义）
  4. 填写 API Base URL（可选）
  5. 填写 API Key
  6. 选择具体模型
  7. 保存配置

UC-12 编辑模型参数

优先级: P0 | 参与者: 用户

描述：用户调整模型生成参数

主流程
  1. 用户选择已有模型配置
  2. 点击「编辑」进入参数设置
  3. 调整参数（Temperature、Top P、Max Tokens 等）
  4. 可选：设置 System Prompt
  5. 可选：配置高级选项（Timeout、Retry 等）
  6. 保存更改

UC-13 切换当前模型

优先级: P0 | 参与者: 用户

描述：用户在对话中切换使用的模型

主流程
  1. 用户点击模型选择器（在输入框附近）
  2. 显示已配置的模型列表
  3. 用户选择目标模型
  4. 后续对话使用新模型

UC-14 保存/加载配置预设

优先级: P0 | 参与者: 用户

描述：用户保存和加载模型配置预设

主流程（保存）
  1. 用户配置好模型参数
  2. 点击「保存为预设」
  3. 输入预设名称（如：创意写作、代码生成）
  4. 预设保存到本地
主流程（加载）
  1. 用户打开预设列表
  2. 选择目标预设
  3. 参数自动填充

UC-15 测试模型连接

优先级: P0 | 参与者: 用户, AI 服务

描述：用户测试模型配置是否正确

主流程
  1. 用户填写模型配置
  2. 点击「测试连接」按钮
  3. 发送测试请求到 AI 服务
  4. 显示测试结果（成功/失败）
  5. 失败时显示错误详情

4. 快捷操作

UC-16 全局快捷键呼出

优先级: P1 | 参与者: 用户

描述：用户通过全局快捷键快速呼出窗口

主流程
  1. 用户在任意应用中按下快捷键（如 Ctrl+Space）
  2. TauriAI 主窗口显示并获得焦点
  3. 输入框自动聚焦
  4. 用户可立即输入
备选流程
  1. 窗口已显示时按快捷键 → 隐藏窗口
