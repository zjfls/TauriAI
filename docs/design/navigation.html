1. 信息架构

TauriAI 采用扁平化的信息架构，主要包含三个顶级视图：

TauriAI
├── 聊天 (Chat) ← 默认视图，核心功能
│ ├── 消息列表
│ ├── 输入区域
│ └── 模型选择器
├── 历史 (History)
│ ├── 对话列表
│ └── 搜索/筛选
└── 设置 (Settings)
    ├── 模型配置
    ├── 外观设置
    └── 通用设置

状态管理

界面状态由 uiStore 管理：

// stores/uiStore.ts
interface UIState {
  activeView: 'chat' | 'history' | 'settings';  // 当前视图
  sidebarExpanded: boolean;                      // 侧边栏展开状态
  theme: 'light' | 'dark' | 'system';           // 主题
}

4. 视图详情

💬 Chat View (聊天视图)

路径: activeView === 'chat'

组件: ChatView → MessageList + InputArea

功能:

  • 显示当前对话的消息列表
  • 发送新消息，接收 AI 流式响应
  • Header 显示对话标题和模型选择器

📜 History View (历史视图)

路径: activeView === 'history'

组件: HistoryPanel

功能:

  • 显示所有历史对话列表（按更新时间排序）
  • 点击对话 → 加载消息 → 跳转到 Chat 视图
  • 支持删除对话、重命名对话

⚙️ Settings View (设置视图)

路径: activeView === 'settings'

组件: SettingsView

功能:

  • 模型配置：添加/编辑/删除 AI 模型
  • 外观设置：主题切换、窗口置顶
  • 通用设置：语言、开机自启

6. 典型用户流程

6.1 新用户首次使用

1

启动应用

应用启动，默认进入 Chat 视图，显示空对话状态

2

配置模型

点击设置图标 → 进入 Settings → 添加 AI 模型配置（API Key 等）

3

开始对话

返回 Chat 视图 → 在 Header 选择模型 → 输入消息发送

6.2 恢复历史对话

1

打开历史

点击历史图标 → 进入 History 视图

2

选择对话

浏览对话列表 → 点击目标对话

3

继续对话

自动跳转到 Chat 视图 → 加载历史消息 → 可继续发送新消息

7. 实现代码参考

视图切换逻辑

// MainLayout.tsx
const { activeView, setActiveView } = useUIStore();

// 根据 activeView 渲染不同内容
const renderContent = () => {
  switch (activeView) {
    case 'chat':
      return <ChatView />;
    case 'history':
      return <HistoryPanel />;
    case 'settings':
      return <SettingsView />;
  }
};

从历史选择对话

// HistoryPanel.tsx
const handleSelectConversation = async (conversationId: string) => {
  // 1. 加载对话消息
  await conversationStore.loadMessages(conversationId);
  
  // 2. 设置当前对话
  conversationStore.setCurrentConversation(conversationId);
  
  // 3. 切换到聊天视图
  uiStore.setActiveView('chat');
};
