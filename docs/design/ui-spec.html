  • Sidebar (侧边栏): 极简设计，仅显示图标（对话、通过 Cmd+K 呼出的历史、设置）。
  • Header (顶部栏): 显示当前对话标题、模型选择器。可拖拽移动窗口。
  • Chat Area (内容区): 消息流列表，自动滚动。
  • Input Area (输入区): 自动增高文本框，支持文件拖拽。

深色模式 (Dark Mode)

完全支持系统级深色模式切换。使用 Tailwind dark: 前缀实现。

  • 背景: bg-slate-50 (Light) / dark:bg-slate-950 (Dark)
  • 文本: text-slate-900 (Light) / dark:text-slate-100 (Dark)
