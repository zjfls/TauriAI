🔌 Tauri Commands

版本: v0.1 | 状态: 评审中 | 更新: 2026-01-04

1. 通用约定

  • 所有 Command 均异步返回 Promise。
  • 错误返回为 Invoke 异常，需使用 try...catch 捕获。
  • 流式数据通过 chat_stream 命令触发，通过 listen 监听事件接收。

2. 命令列表

2.1 Chat (对话)

chat_stream chat

向 AI 发送消息并获取流式响应。此命令立即返回，不等待生成结束。

参数 (Arguments)

名称 类型 说明
message MessageInput 用户发送的消息对象
conversation_id string 当前对话 ID
model_id string? 指定使用的模型配置 ID (可选，默认使用当前激活)

事件 (Events)

  • chat:token - 收到新的文本片段 { id: string, content: string }
  • chat:end - 生成结束 { id: string, full_content: string }
  • chat:error - 生成出错 { id: string, error: string }
abort_chat chat

中断当前正在进行的对话生成。

参数

名称 类型 说明
conversation_id string 目标对话 ID

2.2 Conversation (对话管理)

get_conversations conversation

获取对话列表（按更新时间倒序）。

返回值

Promise<Conversation[]> - 对话摘要列表

get_messages conversation

获取指定对话的所有消息记录。

参数

名称 类型 说明
conversation_id string 对话 ID
limit number? 限制条数（默认 50）
before_id string? 分页游标：获取此 ID 之前的消息

返回值

Promise<Message[]>

create_conversation conversation

创建一个新的空对话。

参数

名称 类型 说明
title string? 可选标题
preset_id string? 可选预设 ID

返回值

Promise<Conversation>

delete_conversation conversation

删除一个对话及其所有消息。

参数

名称 类型 说明
conversation_id string 对话 ID
update_conversation_title conversation

修改对话标题。

参数

名称 类型 说明
conversation_id string 对话 ID
title string 新标题

2.3 Config (配置)

get_app_config config

获取完整应用配置。

返回值

Promise<AppConfig>

save_app_config config

保存应用配置（全量覆盖更新）。

参数

名称 类型 说明
config AppConfig 新的完整配置对象
test_connection config

测试模型连接是否可用。

参数

名称 类型 说明
config ModelConfig 待测试的模型配置

返回值

Promise<{ success: boolean, message: string }>

2.4 System (系统)

set_window_visible system

控制主窗口显示/隐藏。

参数

名称 类型 说明
visible boolean 是否显示
