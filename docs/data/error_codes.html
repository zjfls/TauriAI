📖 业务错误码字典

版本: v0.1 | 状态: 草稿 | 更新: 2026-01-08

本文档记录了 TauriAI 系统中所有已定义的业务错误代码 (AppErrorCode)。

1. 配置类错误 (Config Errors)

错误代码 (Code) 含义 / 触发场景 前端提示 (Message) 建议操作 (Actions)
ModelConfigMissing 用户未选择任何模型，或当前选中的模型 ID 在配置文件中不存在。 未找到有效的模型配置 [去设置] -> 跳转设置页
ConfigLoadFailed 无法从磁盘读取 config.json 文件，可能是文件损坏或权限问题。 无法加载配置文件 [重置配置] -> 恢复默认值

2. AI 服务类错误 (AI Service Errors)

错误代码 (Code) 含义 / 触发场景 前端提示 (Message) 建议操作 (Actions)
OllamaServiceDown 尝试连接 Ollama 本地服务 (localhost:11434) 失败。 连接 Ollama 服务失败，请检查服务是否启动 1. [重试]
2. [如何启动?] -> 打开 Ollama 官网
NetworkTimeout 请求 AI API 超过了设定的时间（默认 30s）未响应。 网络请求超时 [重试]
InvalidApiKey API Key 无效或过期（OpenAI/Anthropic 返回 401）。 API Key 无效 [去设置] -> 检查 Key

3. 系统类错误 (System Errors)

错误代码 (Code) 含义 / 触发场景 前端提示 (Message) 建议操作 (Actions)
DatabaseError SQLite 数据库读写失败。 数据库操作失败 [联系支持] / [查看日志]
