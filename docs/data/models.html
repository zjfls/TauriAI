💾 数据模型

版本: v0.1 | 状态: 评审中 | 更新: 2026-01-04

1. 概览

TauriAI 使用混合存储策略：

  • SQLite (data.db): 存储大量结构化数据（对话历史、消息记录），利用关系型数据库的查询能力。
  • JSON (config.json): 存储应用配置和用户偏好，保持便携性和可读性。

2. 数据库模型 (SQLite)

存储路径: ~/.tauri-ai/data.db

Conversation (对话)

表示一个完整的对话会话。

CREATE TABLE conversations ( id TEXT PRIMARY KEY, -- UUID v4 title TEXT NOT NULL, -- 对话标题 (自动生成或用户修改) model_id TEXT, -- 使用的模型 ID (快照) created_at DATETIME DEFAULT CURRENT_TIMESTAMP, updated_at DATETIME DEFAULT CURRENT_TIMESTAMP );

Rust 结构定义:

pub struct Conversation {
    pub id: String,
    pub title: String,
    pub created_at: DateTime<Utc>,
    pub updated_at: DateTime<Utc>,
    // 关联的模型快照，用于恢复上下文时的参数
    pub model_snapshot: Option<ModelConfig>, 
}

Message (消息)

表示对话中的一条消息。支持多模态内容（文本/图片）通过 JSON 序列化存储在 content 字段，或简单文本存储。

CREATE TABLE messages ( id TEXT PRIMARY KEY, -- UUID v4 conversation_id TEXT NOT NULL, -- 外键 -> conversations.id role TEXT NOT NULL, -- 'user' | 'assistant' | 'system' content TEXT NOT NULL, -- 消息内容 (可能为 JSON 结构以支持多模态) meta TEXT, -- 元数据 JSON (token数,耗时,模型版本等) created_at DATETIME DEFAULT CURRENT_TIMESTAMP, FOREIGN KEY(conversation_id) REFERENCES conversations(id) ON DELETE CASCADE ); CREATE INDEX idx_messages_conversation_id ON messages(conversation_id);

Rust 结构定义:

pub struct Message {
    pub id: String,
    pub conversation_id: String,
    pub role: MessageRole, // Enum: User, Assistant, System
    pub content: MessageContent, // Enum: Text(String), Array(Vec<ContentItem>)
    pub meta: Option<MessageMeta>,
    pub created_at: DateTime<Utc>,
}

#[derive(Serialize, Deserialize)]
pub enum MessageContent {
    Text(String),
    Parts(Vec<ContentPart>) // 支持混合 文本+图片
}

3. 配置模型 (JSON)

存储路径: ~/.tauri-ai/config.json

AppConfig (应用配置)

应用的全局配置根对象。

{
  "appearance": {
    "theme": "system", // system, light, dark
    "alwaysOnTop": false
  },
  "general": {
    "language": "zh-CN",
    "autoStart": true
  },
  "activeModelId": "gpt-4o-default", // 当前选中的模型配置 ID
  "models": [ ... ], // 模型配置列表
  "presets": [ ... ] // 预设列表
}

Rust 结构定义:

#[derive(Serialize, Deserialize)]
pub struct AppConfig {
    pub appearance: AppearanceSettings,
    pub general: GeneralSettings,
    pub active_model_id: String,
    pub models: Vec<ModelConfig>,
    pub presets: Vec<Preset>,
}

ModelConfig (模型配置)

定义一个具体的 AI 模型连接参数。

#[derive(Serialize, Deserialize)]
pub struct ModelConfig {
    pub id: String,          // 唯一标识，如 "gpt-4o-personal"
    pub name: String,        // 显示名称，如 "GPT-4o (Personal)"
    pub provider: String,    // "openai", "anthropic", "ollama"
    pub api_base: Option<String>,
    pub api_key: Option<String>, // 运行时解密/从 Keychain 读取
    pub context_length: Option<usize>,
    
    // Provider 特定参数
    pub parameters: ModelParameters, 
}

#[derive(Serialize, Deserialize)]
pub struct ModelParameters {
    pub temperature: f32,    // 0.0 - 2.0
    pub max_tokens: Option<u32>,
    pub top_p: Option<f32>,
    // ... 其他参数
}

Preset (预设)

预设是"模型配置 + 系统提示词"的组合，用于快速切换场景。

#[derive(Serialize, Deserialize)]
pub struct Preset {
    pub id: String,
    pub name: String,        // 如 "代码助手", "翻译官"
    pub model_config_id: String, // 关联的 ModelConfig ID
    pub system_prompt: String,   // 预设的 System Prompt
    
    // 可选：覆盖模型参数
    pub parameters_override: Option<ModelParameters>,
}

4. 状态管理 (Zustand)

前端 React 应用的运行时状态设计。

Store 结构

useConfigStore

  • config: AppConfig - 完整的配置对象
  • activeModel: ModelConfig - (Computed) 当前激活的模型配置
  • actions: setConfig, updateModel, addPreset, etc.

useConversationStore

  • conversations: Conversation[] - 对话列表（摘要）
  • currentConversationId: string | null
  • messages: Message[] - 当前对话的消息列表
  • streamingMessage: string | null - 正在生成的流式消息内容
  • isGenerating: boolean
  • actions: loadConversation, sendMessage, abortGeneration, etc.
