2. 模块设计

2.1 后端模块 (Rust)

ai_client

职责：AI API 调用、流式处理、多 Provider 支持

核心功能：

  • 统一的 AI Client trait，支持多种 Provider
  • OpenAI / Anthropic / Ollama 实现
  • SSE 流式响应处理
  • 请求重试、超时处理
  • Token 计数（可选）

关键结构：

trait AiClient {
    async fn chat(&self, messages: Vec<Message>, config: &ModelConfig) -> Result<String>;
    async fn chat_stream(&self, messages: Vec<Message>, config: &ModelConfig) -> Result<impl Stream<Item = String>>;
}

config

职责：模型配置管理、预设管理、持久化

核心功能：

  • 模型配置 CRUD
  • 预设保存/加载
  • 配置导入/导出
  • 配置验证

存储位置：~/.tauri-ai/config.json

storage

职责：对话历史存储、查询

核心功能：

  • 对话创建/更新/删除
  • 消息追加
  • 历史查询（分页、搜索）
  • 数据迁移

存储位置：~/.tauri-ai/data.db (SQLite)

system

职责：系统级功能（托盘、快捷键、窗口）

核心功能：

  • 系统托盘图标和菜单
  • 全局快捷键注册
  • 窗口显示/隐藏控制
  • 开机自启（可选）

commands

职责：Tauri Command 入口，连接前端与各模块

核心 Commands：

  • send_message - 发送消息并获取 AI 回复
  • send_message_stream - 流式发送消息
  • get_conversations - 获取对话列表
  • get_config / save_config - 配置管理
  • test_connection - 测试模型连接

2.2 前端模块 (React)

状态管理 (Zustand Store)

Store 划分：

  • useConversationStore - 对话状态（当前对话、消息列表）
  • useConfigStore - 配置状态（模型配置、当前模型）
  • useUIStore - UI 状态（加载中、侧边栏展开）

页面组件

  • ChatView - 主对话界面
  • SettingsView - 设置页面
  • HistoryPanel - 历史对话侧边栏

3. 数据流设计

3.1 发送消息流程

用户输入消息
    │
    ▼
前端: useConversationStore.sendMessage()
    │
    ▼
前端: invoke("send_message_stream", { message, conversationId })
    │
    ▼
Rust: commands::send_message_stream()
    │
    ├─► storage: 保存用户消息
    │
    ▼
Rust: ai_client.chat_stream()
    │
    ▼
AI Service: SSE 流式响应
    │
    ▼
Rust: 通过 Tauri Event 发送 token
    │
    ▼
前端: listen("chat_token") → 更新 UI
    │
    ▼
Rust: 流结束 → storage: 保存 AI 回复
    │
    ▼
前端: 显示完整回复

3.2 配置加载流程

应用启动
    │
    ▼
Rust: config::load_config()
    │
    ├─► 读取 ~/.tauri-ai/config.json
    │
    ▼
前端: invoke("get_config")
    │
    ▼
前端: useConfigStore.setConfig()
    │
    ▼
UI 渲染（显示当前模型等）

5. 技术决策

决策点选择理由
本地存储 SQLite 查询灵活、支持复杂查询、Rust 生态成熟 (rusqlite)
前端状态管理 Zustand 轻量、简洁、TypeScript 友好、无 boilerplate
AI 流式传输 SSE + Tauri Events 标准协议、Rust 侧处理后通过 Event 推送前端
配置存储 JSON 文件 人类可读、易于调试、配置量小
HTTP 客户端 reqwest Rust 生态标准、支持异步、支持 SSE
